API + Database Guide para Website de Lourenço Tomás

Objetivo
--------
Criar uma API backend e uma base de dados que suportem todas as páginas e conteúdos do website atual, permitindo que um painel de administração gerencie e altere tudo de forma centralizada.

Requisitos do Prompt para Criação da API e do Banco de Dados
------------------------------------------------------------
Use este conjunto de parâmetros sempre que for gerar ou descrever o backend:

1. Projeto
   - nome: "Lourenço Tomás Website"
   - descrição: "API para gerenciamento de site de artista com portfolio, blog, homenagens e pedidos de encomenda."
   - stack: "Node.js + Express ou Fastify / PostgreSQL ou MySQL / ORM (Prisma, Sequelize ou TypeORM)"

2. Autenticação de Admin
   - auth_method: "JWT"
   - admin_user: { email, passwordHash, role }
   - roles: ["admin", "editor"]
   - endpoints: ["/auth/login", "/auth/refresh", "/auth/logout"]

3. Banco de Dados
   - database_type: "relacional"
   - engine: "MySQL"
   - nome: "lourenco_tomas"
   - seed: false (opcional)

4. Frontend / Painel Admin
   - painel_admin: true
   - dashboard_url: "/admin"
   - gerencia: ["Home", "Obras", "Corporativos", "Sobre", "Encomendas", "Contacto", "Homenagens", "Blog"]
   - media_upload: true
   - editor_rich_text: true

5. Serviços adicionais
   - email_service: "SMTP ou SendGrid"
   - arquivos_estaticos: "CDN ou armazenamento local public/"
   - upload_media: "local"
   - cache: "Redis"

Página / Conteúdos Gerenciados
--------------------------------

1. Página Home (/)
   - Hero: título, descrição, imagem, elementos de destaque.
   - Marquee: texto de destaque animado.
   - About: texto e imagem de apresentação do artista.
   - Historia: timeline, estatísticas, valores.
   - Gallery: itens de obra, filtros e cards.
   - Process: passos do processo criativo, texto explicativo.
   - Testimonials: depoimentos de clientes.
   - Contact: formulário de contacto e links sociais.
   - Footer / WhatsApp: número, mensagem padrão e redes sociais.

2. Página Obras (/obras)
   - Galeria completa de obras com:
     - filtro por categoria
     - múltiplas peças com título, sub-título, técnica, dimensão, imagem de capa
     - link de preço via WhatsApp
   - CTA de encomenda
   - Estatísticas resumidas do portfolio

3. Página Corporativos (/corporativos)
   - Portfólio de clientes corporativos
   - Cases de empresas com nome, setor, ano, descrição e imagens de trabalhos
   - Seções de serviços oferecidos
   - Processo de criação corporativa em etapas

4. Página Sobre (/sobre)
   - Biografia completa do artista
   - Estatísticas de carreira
   - Valores / pilares do trabalho
   - Linha do tempo de marcos históricos
   - CTA para encomendas ou portfolio

5. Página Encomendas (/encomendas)
   - Lista de serviços disponíveis com preço e features
   - Passos de funcionamento do pedido
   - Formulário de encomenda com campos:
     - nome
     - email
     - telefone
     - tipo de serviço
     - dimensões/tamanho
     - prazo desejado
     - descrição do projeto

6. Página Contacto (/contacto)
   - Canais de contato e links sociais
   - Formulário de mensagem com campos:
     - nome
     - email
     - assunto
     - mensagem
   - Botão de envio para WhatsApp com mensagem pré-formatada

7. Página Homenagens (/homenagens)
   - Lista de homenagens com destaque em stories
   - Cards de cada homenagem com:
     - cover, avatar, categoria, nome, função e título da obra
   - Modal de story em formato carrossel
   - Link para detalhe individual de cada homenagem

8. Página de detalhe de Homenagem (/homenagens/:slug)
   - Hero com imagem de capa, categoria, nome e função
   - Texto introdutório e descrição completa
   - Galeria de imagens relacionadas
   - Lista de vídeos com preview e reprodução
   - Especificações técnicas da obra
   - Links de Instagram e informações do artista

9. Página Blog (/blog)
   - Lista de posts com filtros por categoria
   - Destaque para post em primeiro plano
   - Cards de posts com imagem, categoria, data, título e resumo

10. Página de detalhe de Blog (/blog/:slug)
   - Hero com imagem e título
   - Meta de categoria e data
   - Lead e corpo do texto com parágrafos e citações
   - Seção de posts relacionados
   - CTA para encomenda

Prompt de Exemplo para Gerar a API + BD
---------------------------------------
Crie uma API backend em Node.js com autenticação JWT para um painel de administração. O banco de dados deve ser relacional (PostgreSQL) e conter tabelas para site settings, navegação, galerias, filtros, depoimentos, timeline, vídeos, links sociais, homenagens, mídia de homenagens, stories, cases corporativos, serviços de encomenda, etapas de encomenda, FAQs, posts de blog, mensagens de contato e submissões de encomenda. A API deve expor endpoints CRUD para todos os conteúdos listados e suportar upload de imagens/vídeos. O painel admin deve permitir alterar todos os textos, imagens, links e blocos do site.

Notas Especiais
----------------
- Todo conteúdo deve ser editável via admin.
- Cada página deve ser reconstruída a partir de dados do backend, não de conteúdo hard-coded.
- Os campos `slug` devem ser únicos para homenagens e posts.
- `priceHref` em galleryItems deve ser usado para gerar mensagens do WhatsApp.
- `socialLinks` e `WA_NUMBER` devem ficar em configurações globais.
- As submissões de formulários devem ser armazenadas para revisão no painel.
